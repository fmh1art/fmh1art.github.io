Ph.D. student at Renmin University of China researching
\textbf{scalable data synthesis for agent training}.
I develop methods for \textbf{task generation, interaction-trajectory synthesis, and execution-based data verification},
and use the resulting data for curriculum learning and multi-turn reinforcement learning.

\section{Selected Research Projects}

\project{DeepAnalyze: Scalable Training-Trajectory Synthesis}{ICML 2026}
{Project Lead\quad|\quad Synthetic data, quality filtering, curriculum learning, agentic RL}

\begin{itemize}
  \item Developed \textbf{data-grounded trajectory synthesis} for DeepAnalyze-8B, combining teacher-distilled reasoning and environment-generated interactions in the \textbf{DataScience-Instruct-500K} training corpus.
  \item Built a \textbf{questioner--solver--inspector} pipeline: generate tasks and acceptance criteria from real data, execute multi-turn solutions, and filter trajectories using interaction checks and resulting environment changes.
  \item Implemented a curriculum from single-skill SFT to multi-skill cold-start training and \textbf{GRPO}, using approximately 470K, 20K, and 15K samples, respectively.
  \item Evaluated on \textbf{12 benchmarks}; achieved \textbf{38.88\% on DABStep} and \textbf{61.7\% on DS-1000}, versus 15.34\% and 54.8\% for the single-ability training variant.
\end{itemize}

\project{DeepPrep: Verifiable Task Synthesis for Agent Training}{VLDB 2026}
{Project Lead; First Author\quad|\quad Executable supervision, reversible corruption, multi-turn RL}

\begin{itemize}
  \item Designed a synthesis method that converts SQL workloads into \textbf{source tables, target specifications, and executable pipelines}; adds \textbf{reversible noise} and verifies recovery to preserve task solvability.
  \item Constructed \textbf{6,788 training tasks}, with pipelines spanning \textbf{31 operator types} and up to \textbf{28 steps}; trained agents through operator-level SFT, verified reasoning trajectories, and GRPO with hybrid rewards.
  \item Synthetic training data improved \textbf{out-of-domain accuracy by 37.0 percentage points} over Parrot training on Synth-Bird (Qwen3-8B, data ablation); tree-based execution supports backtracking and pipeline repair.
\end{itemize}

\project{Interactive Memory \& Recursive Self-Improvement (RSI) for World Models}{Ongoing}
{Project Lead\quad|\quad World model evaluation, scalable data curation, training, self-improvement}

\begin{itemize}
  \item Proposed an \textbf{interactive-memory benchmark for action-conditioned world models}, formalizing memory through \textbf{Encoding, Maintain, Update, and Read} and evaluating reactive response, memory persistence, and memory plasticity across temporal-retention and interference settings.

  \item Built an automated \textbf{Isaac Sim} evaluation pipeline with programmatically generated cases and ground-truth state supervision; reproduced and evaluated \textbf{nine representative world models}, including Ctrl-World, WorldMem, iVideoGPT, HyDRA, and Oasis, under a unified evaluation protocol.

  \item Built a \textbf{fully automated multimodal annotation system} for world-model training, covering atomic action segmentation, semantic and object-interaction labels, object-state changes, camera pose, and 3D hand motion; supports \textbf{100+ videos concurrently} at approximately \textbf{\$40 API cost per raw video hour}, with annotation quality validated through manual audits.

  \item Developing a \textbf{Recursive Self-Improvement} pipeline linking data annotation, training-recipe construction, distributed training, evaluation, and recipe refinement; uses model weaknesses to drive hard-example mining, curriculum construction, active data selection, and data-mixture optimization.
\end{itemize}

\section{Additional Research Projects}

\project{CoDA-Bench \& TACO: Scalable, Verifiable Task Construction}{ICML / VLDB 2026}
{Co-author\quad|\quad Task synthesis, execution verification, difficulty refinement}

\begin{itemize}
  \item \textbf{CoDA-Bench:} Co-authored a benchmark of \textbf{1,009 tasks across 31 data communities}, built from executable notebook solutions through task reconstruction, adversarial refinement, and human verification.
  \item \textbf{TACO:} Co-authored a benchmark combining \textbf{1,500 expert-annotated} and \textbf{13,000 synthetic} NL--SQL pairs, using query-structure sampling, schema-constrained generation, and quality checks.
\end{itemize}

\project{EvoCost \& SkillAdam: Agent Self-Evolution}{ICLR 2027 submissions}
{EvoCost: Lead, First Author\quad|\quad SkillAdam: Co-author}

\begin{itemize}
  \item \textbf{EvoCost:} Developed harness evolution that mines avoidable interactions from trajectory dependency graphs and validates updates to instructions, skills, tools, and executor logic with a fixed backbone model.
  \item \textbf{SkillAdam:} Co-authored skill optimization with persistent issue memory and adaptive edit budgets; reduced optimization tokens by \textbf{67.3\%} versus SkillOpt on DeepPlanning, with test accuracy improving from 21.7\% to 28.3\%.
\end{itemize}

\project{AutoPrep \& BATCHER: Task-Aware Data Preparation}{VLDB 2025 / ICDE 2024}
{Project Lead; First Author\quad|\quad Data transformation, demonstration selection, inference efficiency}

\begin{itemize}
  \item \textbf{AutoPrep:} Developed Chain-of-Clauses planning and tool-augmented execution; improved NL2SQL accuracy by \textbf{12.22 / 13.23 points} on WikiTQ / TabFact, averaged across evaluated backbones.
  \item \textbf{BATCHER:} Developed coverage-based demonstration selection and token-aware batch allocation; batch prompting reduced API cost by \textbf{4--7$\times$} versus standard prompting across eight ER datasets.
\end{itemize}
